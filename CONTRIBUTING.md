# Contributing

Use the Node.js version pinned in `.node-version` (24), run `npm ci`, and read `AGENTS.md`, `DESIGN.md` and `docs/architecture.md` before editing. Keep changes small and in scope; all code, UI copy and documentation are English.

Run `npm run check`, `npm run format:check` and `npx expo-doctor`. For camera, media or persistence changes, describe the device/OS, steps, expected/actual results, permissions and restart behavior in the pull request. Browser checks do not cover native behavior.

Never commit real names, photos, credentials, customer code or generated build output. New dependencies require a demonstrated need and license review. AI-assisted contributions require human review of the diff and the same verification as any other contribution.
